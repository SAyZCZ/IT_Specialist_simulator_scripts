CALL STATISTICS
===============

The program must summarize the number of calls answered during four consecutive hours.

1. Create first_hour, second_hour, third_hour and fourth_hour variables.
2. Read each value separately with input() and convert it to a number.
3. Create hours_count and assign 4. It represents the number of analyzed hours. Do not read it with input() and do not store the number of calls in it.
4. Calculate total_calls as the sum of first_hour, second_hour, third_hour and fourth_hour.
5. Calculate average_calls by dividing total_calls by hours_count.
6. Print total_calls and average_calls in the terminal.

Example: for 10, 20, 30 and 40, total_calls should be 100 and average_calls should be 25.
The program must perform the calculation for any numbers entered by the user.
